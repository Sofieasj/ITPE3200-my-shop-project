# ITPE3200 Course Practice Project: My Shop

For this project I am following the tutorials and guidelines given by my course professor.  
My goal upon completion of the project, is to make changes based on what I have learned in my previous years in university,
such as strictly using semantic HTML, moving from JS to TS, and using variables with block-scope rather than function-scoped. I
also plan to write tests in Playwrigth and NUnit or xUnit, though preferably I would have like to follow TDD.  

I would also like to create diagrams of the architecture and flow of the program, as documentation.  
Another goal is to test out DigDir's Designsystemet as an alternative to Bootstrap, with a strong focus on accessibility.

## Technologies and patterns
* MVC- and MVVM-patterns
* ASP.NET Core, C#
* Dynamic razor-pages
* Bootstrap
* SQLite DB, with async and lazy loading
