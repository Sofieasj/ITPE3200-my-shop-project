# My Shop

This project is a practice e-commerce application developed as part of the ITPE3200 course. It follows the guidance, tutorials, and project structure provided by the course professor, while also incorporating additional improvements and ideas based on my own software development learning and professional interests.

The goal of this project is to build a realistic web application that strengthens my understanding of full-stack development, clean architecture, and modern engineering practices. Beyond completing the guided implementation, I use this project to explore topics that are important in industry work, such as semantic HTML, TypeScript adoption, accessibility, testing, and maintainable application design.

## Project focus

This application is designed to practice and demonstrate:
- ASP.NET Core development with C#
- MVC and MVVM design patterns
- Dynamic Razor Pages
- SQLite database usage
- Asynchronous programming and lazy loading
- Responsive UI development
- Testing and quality assurance practices
- Accessibility-oriented frontend design

## Learning goals

A major part of this project is to apply concepts I have learned through both coursework and previous university experience, including:
- using semantic HTML consistently
- migrating from JavaScript to TypeScript where appropriate
- writing cleaner, more maintainable code
- using block-scoped variables instead of function-scoped patterns
- improving application structure and separation of concerns
- applying testing practices with Playwright and NUnit/xUnit
- exploring TDD approaches where feasible

## Additional goals

I also want this project to serve as a foundation for deeper documentation and engineering exploration. Planned work includes:
- creating architecture and flow diagrams
- documenting project structure and decision-making
- evaluating alternative UI systems such as DigDir’s Designsystemet
- improving accessibility and user experience
- expanding automated testing coverage
